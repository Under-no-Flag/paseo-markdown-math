# 验收说明

## 自动检查

`npm run check` 构建客户端、服务端、Mermaid iframe 脚本与内嵌字体，运行三组严格类型检查及 27 项单元测试。覆盖公式分隔符、数学围栏、宏隔离、HTML/URL 注入、代码不误解析、Mermaid 源码转义、标题锚点、图片地址、空文档、超限内容，以及真实临时目录中的资源解析、中文编码、缺失文件、大小限制、路径越界和符号链接越界。

`npm run verify:host` 使用安装的 Paseo 0.13.0 编译器生成客户端及服务端 bundle，并在无 DOM 的模拟 native 环境验证客户端模块加载、addFilePanel 注册与 cleanup。不是宿主 UI 或手机实测。

`npm run dev` 后，另一个终端运行 `npm run test:browser`（已安装 Chrome）。测试加载同一编译后的客户端、真实 SDK hooks，以及复用服务端资源函数的本地中间件。结果与截图写入 `test-results/`。会临时修改并在 finally 中恢复示例 `examples/guide/details.md`；若强制终止进程，需检查示例末尾是否留下测试标记。

## Paseo 桌面手工验收

1. 客户端和当前 host 均为 0.13.x，插件 `paseo-markdown-math` 显示 running。
2. 将本仓库作为工作区，打开 `examples/math-demo.md`，选择 **Markdown + Math**。
3. 确认公式、流程图、本地 SVG 显示。展开 Mermaid 源码。
4. 点击「打开详细说明」，确认跳到详细说明标题，时序图与嵌套相对图片正常；点击「← 返回」。
5. 保存当前原文件确认自动更新；打开链接文档后修改目标文件，约 2 秒后应更新。单独更换图片后点击「刷新」。
6. 切换源码/预览和明暗主题；打开外链应出现独立页面。
7. 删除测试副本或引用不存在的图片，确认就地错误提示；恢复后预览应恢复。
8. 用 Open with 切回内置面板，确认原文件未被插件写入。

远程 host 需要单独安装、单独验收。原生移动端从 v0.3 起提供主机渲染预览，见下文。

### iPhone 上仍需确认

本机没有 iOS simulator runtime，未声称真机通过。完成以下检查才算 iOS 端完整验收：

1. 主机安装 Chrome/Edge/Chromium、插件更新至 0.3.0 并 running；iPhone 与 daemon 均为 Paseo 0.13.x。
2. iPhone 重新打开 `examples/math-demo.md` → Markdown + Math，看到行内/块级公式、矩阵、流程图及图片，不是源码回退。
3. 双指放大/缩小，滚动跨越 PNG 分片，确认没有断层、手势冲突、闪退；旋转屏幕后内容重新适配。
4. 打开「详细说明」、验证时序图/嵌套图片/#详细说明定位；返回，点击本页锚点和外链。
5. 切换明暗主题、源码、刷新；在主机编辑文件后手机自动更新。预览文字复制从源码视图进行。
6. 主机浏览器不可用时出现可操作错误，恢复浏览器后重试成功。

Android、Windows/Linux 主机浏览器发现、远程网络高延迟、原生 VoiceOver 和 iOS 双指缩放尚未实机验证。图像预览不支持选择正文、动画图片或 Mermaid 交互回调；网络图片通过设备浏览器打开。

## 2026-10-26 v0.3.1 长文档超限修复

0.3.0 的 PNG 分片仍一次返回整篇截图；超过总计 1,600 万像素时直接失败。0.3.1 的 RPC 增加页码，只截取、传输和挂载当前页（最多 3,000 CSS 像素高、三块 PNG）。页边界优先选择正文块边界；锚点使用完整文档坐标选择目标页，再换算为页内位置。整篇排版高度上限调整为 240,000 CSS 像素，字符限制仍为 120,000。

- 自动检查增加分页覆盖、块边界选择、超高块回退、去重/乱序边界用例，总计 30 项测试。
- 主机回归增加超过旧 1,600 万像素及 24,000 CSS 像素高度的文档：验证首页/中间页/末页成功，单页像素预算、页码夹取、链接坐标及完整锚点。
- 原生分支交互增加长文档上一页/下一页、首尾跨页锚点、390px 与 1024px 宽度、最多三块图像、源文件变短后重置页码；原有短文档交互继续回归，共 13 组。
- 换页后旧图像组件卸载，内容、宽度和主题变化回到首页，过期响应继续丢弃。
- 主机及 RN Web 适配器验证不等同于 iPhone 实机内存/手势验收；仍需在此前报错的原始文件上确认。
